🔬 Arquitectura funcional del ventilador mecánico

El siguiente diagrama representa de manera simplificada los principales subsistemas que intervienen en el funcionamiento de un ventilador mecánico.

El sistema recibe energía, procesa información mediante la unidad de control, regula el suministro de gases, entrega el flujo al paciente y utiliza sensores para supervisar continuamente las variables de funcionamiento.

🔁 Retroalimentación del sistema Los sensores permiten obtener información sobre las condiciones de funcionamiento. Esta información es procesada por la unidad de control para supervisar el sistema y, cuando corresponde, generar acciones y alarmas.

📋 Descripción de los bloques

Bloque Función Relación con BioVent
⚡ Alimentación Proporciona la energía necesaria para el funcionamiento del equipo y puede incluir una batería de respaldo. Cable de alimentación, batería y estado del equipo.
🧠 Unidad de control Procesa las señales provenientes de los sensores y coordina el funcionamiento del ventilador. Encendido y prueba de funcionamiento.
📊 Sensores Permiten medir variables necesarias para supervisar las condiciones de ventilación. Punto de inspección de sensores y pruebas funcionales.
💨 Sistema neumático Gestiona y regula el suministro de gases utilizados durante la ventilación. Circuito respiratorio, filtros y prueba de funcionamiento.
⚙️ Actuadores Permiten controlar el flujo y las condiciones de entrega de los gases. Prueba de funcionamiento del equipo.
🖥️ Interfaz / Pantalla Permite al usuario visualizar información y configurar parámetros del equipo. Inspección de pantalla.
🔔 Sistema de alarmas Informa mediante señales visuales y sonoras sobre determinadas condiciones que requieren atención. Punto de alarmas del checklist.
🔄 Circuito respiratorio Conduce los gases entre el ventilador y el paciente. Circuito respiratorio y filtros.
🫁 Paciente Recibe el soporte ventilatorio proporcionado por el equipo. Representa el objetivo final del sistema de ventilación.

📌 Nota académica

El presente diagrama corresponde a una representación funcional simplificada de un ventilador mecánico. La arquitectura interna, los componentes y los sistemas específicos pueden variar dependiendo del fabricante y del modelo del equipo.

Para el proyecto BioVent, este esquema se utiliza como referencia para relacionar el funcionamiento general del ventilador con las actividades de inspección, mantenimiento y seguimiento realizadas mediante la plataforma.
