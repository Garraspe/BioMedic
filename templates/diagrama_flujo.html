Flujo de funcionamiento de la plataforma BioMedic

Diagrama de flujo de la programación

El siguiente diagrama representa de manera visual el funcionamiento general de la plataforma web BioMedic. Se muestran las principales etapas que sigue el sistema desde el inicio de la aplicación hasta la obtención de un resultado.

INICIO
1. Ingreso a BioMedic El usuario accede a la plataforma web.
2. Selección del módulo El usuario selecciona Equipos, Mantenimientos, Checklists, Dashboard o Manuales.
3. Ingreso de información El usuario registra o consulta información en el módulo seleccionado.
¿Los datos son correctos?
NO
Corregir información El sistema solicita corregir los datos ingresados.
SÍ
4. Procesar información Flask procesa la solicitud realizada por el usuario.
5. Base de datos La información se almacena o consulta en la base de datos SQLite.
6. Mostrar resultado BioMedic presenta la información actualizada al usuario.
FIN

¿Qué representa este diagrama?

  • Inicio: representa el momento en que el usuario comienza a utilizar la plataforma.
  • Selección del módulo: el usuario decide qué función de BioMedic desea utilizar.
  • Ingreso de información: se registran datos de equipos, mantenimientos, checklists u otra información.
  • Validación: el sistema verifica que la información ingresada sea correcta.
  • Procesamiento: Flask recibe la solicitud y ejecuta la lógica correspondiente.
  • Base de datos: SQLite almacena o proporciona la información solicitada.
  • Resultado: el sistema muestra al usuario la información procesada.
  • Fin: finaliza el proceso seleccionado.
